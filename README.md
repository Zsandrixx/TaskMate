## Project Description

TaskMate is a simple "To Do List" app made using React Native and Expo. It helps users manage their tasks by adding a task name, description, and due date. They can also track the unfinished task that are not yet done. This app can help users organize their activities and remember the tasks they need to finish.

## Features

- Add a task and its due date.
- See all tasks in one list.
- Check the status of tasks.
- Keep daily tasks organized.
- Delete task once done
- Alerts when a task name already exists.
- Alert message when task has been     successfully added.

## Technologies Used

- React Native
- Expo
- JavaScript
- Visual Studio Code

## How to Run the Project

1. Install Node.js on your computer.
2. Download or clone the project from GitHub.
3. Open the project folder in the terminal.
4. Install the needed packages by typing:

   ```bash
   npm install
   ```
   if not you may also try:

   ```bash
   npm.cmd install
   ```

5. Start the app by typing:

   ```bash
   npx expo start
   ```
   if not you may also try:

   ```bash
   npm.cmd expo start
   ```


6. Scan the QR code using Expo Go or open the app in an emulator. You may download the Expo Go app on Google play or any playstore of your choice.
